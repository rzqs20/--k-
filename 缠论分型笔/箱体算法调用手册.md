## 一、核心类一览

| 类名 | 文件 | 说明 |
|------|------|------|
| `BoxFinderBase` | `core/box_finder.py` | 抽象基类，定义 `find(fxs, bars, start_dt=None)` 接口 |
| `BoxFinder` | `core/box_finder.py` | 全量算法，用所有分型的前60%分位算阈值，箱体随数据变化 |
| `IncrementalBoxFinder` | `core/box_finder.py` | 增量算法，滚动窗口阈值+确认锁定，箱体确认后不随后续数据变化 |
| `ChanAnalyzer` | `core/chan_analyzer.py` | 缠论分析器，内部自动做K线合并→分型→笔→线段→箱体 |
| `ReportRenderer` | `core/report_renderer.py` | 报告生成器，输出终端文本和HTML图表 |

## 二、快速调用

### 2.1 全量算法（默认）

```python
import sys
sys.path.insert(0, r'D:\量化k线\缠论分型笔')
from datetime import datetime
from chan_report import load_bars
from core import ChanAnalyzer

sdt = datetime(2024, 1, 1)
edt = datetime(2026, 9, 2)

# 加载K线（自动加载600根预热数据）
label, bars, prewarm = load_bars('000301', 'SZ', '日线', sdt, edt)

# 创建分析器（默认用BoxFinder全量算法）
ana = ChanAnalyzer(bars, symbol=label, freq='日线', start_dt=sdt)

# 获取箱体列表
boxes = ana.find_boxes()
for b in boxes:
    print(f"{b['start']:%Y-%m-%d} ~ {b['end']:%Y-%m-%d} | "
          f"箱体[{b['dd']:.2f},{b['gg']:.2f}] | {b['n_fx']}分型")
```

```python

                   box_finder=box_finder, start_dt=sdt)

```

## 三、BoxFinder（全量算法）参数

```python
BoxFinder(
    slope_quantile=0.6,   # 斜率分位数（0~1），越小越严格
    chg_quantile=0.6,     # 涨跌幅分位数（0~1），越小越严格
    min_fx=4,             # 箱体最少分型数
    min_h_pct=0.5,        # 箱体最小全高（%）
    max_h_pct=50.0        # 箱体最大全高（%）
)
```

**核心逻辑**：
- 阈值 = 所有分型斜率/涨跌幅的前60%分位（全量重算）
- 三层向前扩展：段首允许 + 提前向后扩展 + 事后向后扩展
- 确认条件：≥4分型、2顶2底、全高0.5%~50%、ZG>ZD

**特点**：箱体数量和位置随数据变化，后续剧烈行情会拉高阈值，导致早期箱体消失。

## 四、IncrementalBoxFinder（增量算法）参数

```python
IncrementalBoxFinder(
    slope_quantile=0.6,   # 斜率分位数（0~1），越小越严格
    chg_quantile=0.6,     # 涨跌幅分位数（0~1），越小越严格
    min_fx=4,             # 箱体最少分型数
    min_h_pct=0.5,        # 箱体最小全高（%）
    max_h_pct=50.0,       # 箱体最大全高（%）
    window_size=20        # 滚动窗口大小（最近多少个分型计算阈值）
)
```

**核心逻辑**：
1. **滚动窗口阈值**：每到一个分型，用它之前最近20个分型的前60%分位算阈值
2. **段首允许**：当前不平缓但后面连续≥3个平缓 → 当前分型也作为起点
3. **层2提前向后扩展**：run到4个分型时，向前找1个半区内分型
4. **层3事后向前扩展**：确认时向前找1-2个半区内分型（只执行一次）
5. **确认锁定**：箱体确认后标记已确认范围，后续遍历跳过，不被后面的数据修改
6. **预热机制**：`start_dt` 之前的分型只用于计算阈值，不参与箱体构成

**特点**：箱体一旦确认就锁定，不随后续数据变化。适合实盘和回测。

## 五、ChanAnalyzer 参数

```python
ChanAnalyzer(
    bars,               # K线列表（RawBar对象）
    symbol="",          # 股票代码，如 "000301.SZ"
    freq="",            # 周期，如 "日线"、"30分钟"
    max_bi_num=None,    # 最大笔数（None不限制）
    min_bi_len=6,       # 笔的最小K线数
    box_finder=None,    # 箱体识别器，None则默认BoxFinder()
    start_dt=None       # 起始日期，之前的分型只用于预热（增量算法用）
)
```

**主要方法**：
- `find_boxes()` → 返回箱体列表
- `find_trends()` → 返回趋势列表
- `find_segments()` → 返回线段列表
- `bi_list` → 笔列表
- `fxs` → 分型列表
- `segments` → 线段列表

## 六、缠论基础结构（分型 / 笔 / 线段）

ChanAnalyzer 内部自动完成 **K线合并 → 分型 → 笔 → 线段** 的计算，通过属性直接获取。

### 6.1 获取方式

```python
ana = ChanAnalyzer(bars, symbol=label, freq='日线', start_dt=sdt)

# 分型（笔端点，已去重）
fxs = ana.fxs

# 笔列表
bis = ana.bi_list

# 线段列表（含未完成段）
segs = ana.segments

# 已完成线段
finished_segs = ana.finished_segments
```

### 6.2 分型（FX）

```python
fx = fxs[0]
fx.dt       # 分型时间 datetime
fx.mark     # 'G' 顶分型 / 'D' 底分型
fx.high     # 最高价
fx.low      # 最低价
fx.fx       # 分型值（顶=high，底=low）
fx.elements # 构成它的3根NewBar列表

# 方法
fx.power_str()      # 分型强度：'强'/'中'/'弱'
fx.power_volume()   # 构成分型的3根K线成交量之和
```

**分型强度判断**：
- 底分型：第3根K线收盘价 > 第1根K线最高价 → 强；> 第2根K线最高价 → 中；否则弱
- 顶分型：第3根K线收盘价 < 第1根K线最低价 → 强；< 第2根K线最低价 → 中；否则弱

### 6.3 笔（BI）

```python
bi = bis[0]
bi.fx_a          # 起点分型 FX
bi.fx_b          # 终点分型 FX
bi.direction     # 'Up' 向上笔 / 'Down' 向下笔
bi.fxs           # 笔内分型列表
bi.bars          # 笔的NewBar列表（无包含关系K线）

# 属性
bi.start_dt      # 起点时间
bi.end_dt        # 终点时间

# 方法
bi.get_high()          # 笔内最高价
bi.get_low()           # 笔内最低价
bi.get_power()         # 价差力度：|终点分型值 - 起点分型值|
bi.get_power_volume()  # 成交量力度：笔内（不含首尾）K线量能之和
bi.get_length()        # 笔的无包含关系K线数量
```

### 6.4 线段（Segment）

```python
seg = segs[0]
seg.fx_a       # 线段起点分型 FX
seg.fx_b       # 线段终点分型 FX
seg.direction  # 'Up' 向上线段 / 'Down' 向下线段
seg.bis        # 构成线段的笔列表
seg.finished   # True已完成 / False未完成（仍在延伸）
```

**线段规则**：由3笔及以上构成，方向由首笔决定；未完成段表示尾部笔数不足以确认，仍在延伸。

### 6.5 K线数据结构

```python
# 原始K线
RawBar(symbol, dt, open, close, high, low, vol, amount, id, freq)

# 去包含关系后的K线
NewBar(symbol, dt, open, close, high, low, vol, amount, id, freq, elements)
# elements: 构成它的原始K线列表（合并后多根）
```

## 七、箱体数据结构

每个箱体是一个字典，关键字段：

```python
{
    'start': datetime,        # 箱体开始时间
    'end': datetime,          # 箱体结束时间
    'gg': float,              # 箱体上沿（最高价）
    'dd': float,              # 箱体下沿（最低价）
    'zg': float,              # 重叠区上沿（最低顶）
    'zd': float,              # 重叠区下沿（最高底）
    'p90': float,             # P90线（上沿附近）
    'p10': float,             # P10线（下沿附近）
    'n_fx': int,              # 分型数量
    'n_bis': int,             # 笔数量
    'bars': int,              # K线数量
    'full_h_pct': float,      # 全高百分比
    'reason': str,            # 识别原因说明
    'standard_score': int,    # 盘整标准度评分
    'standard_label': str,    # 盘整标准度标签（强/中/弱）
    'unified_breakout': dict, # 统一突破分析结果
}
```

## 十、注意事项

1. **预热数据**：`load_bars` 会自动在起始日期前加载600根K线，用于缠论结构构建和增量算法阈值计算。HTML报告不显示预热数据。
2. **增量算法必须传start_dt**：否则前几个分型会因窗口数据不足导致阈值为999（无限宽松），产生误判。
3. **全量算法的箱体不稳定**：后续数据会改变阈值，导致早期箱体消失。需要稳定箱体时用增量算法。
4. **RawBar字段**：symbol/dt/open/close/high/low/vol/amount/id/freq，全部必填。
5. **Python环境**：`C:\Users\xyz\AppData\Local\Programs\Python\Python310\python.exe`（唯一带duckdb的Python）。
