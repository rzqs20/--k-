## 二、核心API

### 2.1 获取数据

| API | 说明 | 示例 |
|-----|------|------|
| `khGet(data, "first_stock")` | 获取第一只股票代码 | `sc = khGet(data, "first_stock")` |
| `khGet(data, "stocks")` | 获取股票池列表 | `for sc in khGet(data, "stocks"):` |
| `khGet(data, "date_num")` | 获取当前日期(数值格式) | `dn = khGet(data, "date_num")` |
| `khPrice(data, sc, "open")` | 获取当前开盘价 | `p = khPrice(data, sc, "open")` |
| `khHistory(sc, fields, count, freq, end_time, fq="pre")` | 获取历史K线 | `hist = khHistory(sc, ["close"], 60, "1d", dn, fq="pre")` |

### 2.2 持仓与信号

| API | 说明 | 示例 |
|-----|------|------|
| `khHas(data, sc)` | 检查是否持有 | `if khHas(data, sc):` |
| `generate_signal(data, sc, price, amount, direction, reason)` | 生成交易信号 | `signals.extend(generate_signal(data, sc, p, 1.0, 'buy', '买入原因'))` |

**direction**: `'buy'` 或 `'sell'`
**amount**: 仓位比例（1.0=全仓，0.1=10%仓）

### 2.3 技术指标

| API | 说明 | 示例 |
|-----|------|------|
| `khMA(sc, period, end_time)` | 移动平均 | `ma = khMA(sc, 5, dn)` |
| `RSI(closes, period)` | RSI（MyTT库） | `r = RSI(closes, 14)` |
| `MACD(closes, fast, slow, signal)` | MACD | `dif, dea, macd = MACD(closes, 12, 26, 9)` |

### 2.4 历史数据结构

```python
hist = khHistory(sc, ["open", "high", "low", "close", "volume"], 60, "1d", dn, fq="pre")
# hist[sc] 是一个DataFrame
# hist[sc]["close"].values 是收盘价数组
# hist[sc]["open"].values 是开盘价数组
```

## 三、策略编写规范

### 3.1 无未来函数
- `khHandlebar` 中只能使用当前日期及之前的数据
- `khHistory` 的 `end_time` 必须传当前日期 `dn`
- 不能用未来数据判断当前信号

### 3.2 信号生成
- 买入：`generate_signal(data, sc, price, amount, 'buy', reason)`
- 卖出：`generate_signal(data, sc, price, amount, 'sell', reason)`
- `amount` 是仓位比例，不是股数
- 卖出时 `amount=1.0` 表示全部卖出

### 3.3 多股票策略
```python
for sc in khGet(data, "stocks"):
    # 对每只股票判断
    if buy_condition and not khHas(data, sc):
        signals.extend(generate_signal(data, sc, p, 0.2, 'buy', reason))
    elif sell_condition and khHas(data, sc):
        signals.extend(generate_signal(data, sc, p, 1.0, 'sell', reason))
```

## 五、注意事项

1. **编码**: 文件必须 `# coding: utf-8`
2. **导入**: 必须 `from khQuantImport import *`
3. **函数名**: `init` 和 `khHandlebar` 是固定入口
4. **日志**: 用 `logging.info()` 输出日志
5. **复权**: `khHistory` 默认 `fq="pre"` 前复权
6. **频率**: `"1d"` 日线，`"1m"` 1分钟，`"5m"` 5分钟
7. **参数**: 建议用 `params` 字典集中管理
