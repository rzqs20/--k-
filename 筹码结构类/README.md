# 筹码结构类 —— 筹码分布（CYQ）分析与交互报告

> 本文档面向**所有协作智能体**（情绪判断类 / 回测策略类）。
> 本文件夹归**筹码结构算法智能体**管理：产出稳定的筹码分布算法与交互报告，
> 供情绪判断类做前置输入、供策略类做买卖点辅助。

---

## 1. 这个文件夹负责什么

**一句话：用「前复权日线 + 三角形分布 + 滚动 250 日时间衰减」计算每只股票逐日的筹码分布（CYQ），输出获利盘/套牢盘/平均成本/集中度/筹码峰等衍生指标，并提供可拖动时间轴的交互式图表报告。**

### 职责边界

| 角色 | 负责 | 不负责 |
|---|---|---|
| **筹码智能体（本文件夹）** | 筹码分布核心算法（`chip_distribution.py`）、交互报告（`chip_report.py`） | 情绪周期判断、KhQuant 策略编写 |
| **情绪判断类**（后续） | 基于筹码结构（获利盘/集中度/峰位）+ 市场数据做情绪判断 | 筹码算法本身 |
| **回测策略类** | 把筹码指标封装进 KhQuant 策略 | 算法数学逻辑 |

### 与上层的关系（为什么先做筹码）

筹码结构是**情绪判断的前置**：
- 获利盘比例 → 抛压大小 → 情绪能否延续
- 筹码集中度 → 主力控盘 → 启动/退潮信号
- 套牢盘密集峰位 → 上方压力 → 突破难度
- 平均成本 → 多空分界 → 资金盈亏结构

## 3. 算法说明（chip_distribution.py）

### 3.1 价格口径与数据

- **前复权**（`open_front/high_front/low_front/close_front`），与 KhQuant 回测口径一致，且除权无价格跳变，筹码分布不会错乱。
- 数据源：`D:\khData\<SH|SZ>\<code>.db` 的 `kline_1d` 表。

### 3.2 分布算法（经典三角形分布法）

1. 每根日K的成交量按**三角形分布**摊到 `[low, high]` 区间，三角形顶点在**收盘价**（当日成交最集中的价位）。
2. **固定时间衰减**：每日旧筹码整体留存 `λ=0.98`（`turn` 换手率字段在 khData 中全为空、无流通股本，故不用换手率模型；接口已预留，未来有换手数据可切换）。
   - λ=0.98 → 60 日留存 30%、120 日留存 9%、250 日留存 0.6%：约半年筹码主导分布。
3. **滚动窗口 250 日**：窗口外筹码按 `λ^250` 整体移除，增量 O(1)/日更新。
4. **无未来函数**：截至某日的分布只用当日及之前数据，可直接用于回测。

### 3.3 衍生指标（每交易日一个 ChipSnapshot）

| 字段 | 含义 | 上层用途 |
|---|---|---|
| `profit_ratio` | 获利盘比例（现价下方筹码占比） | 抛压/情绪 |
| `trapped_ratio` | 套牢盘比例 = 1 - 获利盘 | 上方压力 |
| `avg_cost` | 平均成本（筹码重心） | 多空分界 |
| `conc90` / `conc70` | 90%/70% 筹码集中度，`(P95-P5)/(P95+P5)` | 控盘程度 |
| `p5` / `p95` | 90% 区间下/上沿价 | 支撑压力带 |
| `peaks` | 筹码峰列表 `[{price, value, share}]`，按量排序 | 峰位/单峰双峰 |
| `peak_count` | 显著峰数量（share ≥ 3% 平滑后局部极大） | 单峰密集 vs 多峰发散 |

### 3.4 参数（均可调）

| 参数 | 默认 | 说明 |
|---|---|---|
| `window` | 250 | 滚动窗口（交易日） |
| `decay` | 0.98 | 每日筹码留存率 |
| `n_bins` | 200 | 价格分档数 |
| `smooth` | 3 | 峰检测平滑窗口 |
| `peak_min_share` | 0.03 | 峰最小占比 3% |

## 4. 交互报告（chip_report.py）

### 4.1 命令行用法

```powershell
# 最近 500 个交易日（默认）
python chip_report.py 000001 SZ
# 指定展示天数
python chip_report.py 000301 SZ 800
# 指定区间
python chip_report.py 000001 SZ 500 2024-01-01 2026-09-02
```

> Python 环境：`C:\Users\xyz\AppData\Local\Programs\Python\Python310\python.exe`
> （唯一带 pandas/duckdb/numpy 的 Python）。

### 4.2 交互方式

- **底部时间轴滑块（dataZoom）**：拉动/缩放 x 轴 → 主图右侧蓝线移至可视区间【最后一天】，筹码峰图同步切换为该日分布（主交互）。
- **悬停 K 线**：鼠标移到任意 K 线 → 筹码峰图实时跟随该日。
- 主图横线：红=当日收盘、灰=平均成本、黄虚线=筹码峰位；蓝竖线=当前筹码对应日期。
- 中图：获利盘比例曲线（50% 多空参考线）。
- 筹码峰图：横轴筹码占比%，纵轴价格（上高下低，**自适应筹码密集带**）；红=获利盘、绿=套牢盘。

### 4.3 输出

`reports/<code>_<EX>_筹码结构_<YYYYMMDD>.html`（约 0.6 MB），自动用浏览器打开。

snaps = cd.compute(rows)          # List[ChipSnapshot]，与 rows 等长

# 4) 全量指标（供回测逐日遍历）
for s in snaps:

## 6. 已知限制

- 无换手率/流通股本数据 → 用固定时间衰减替代换手衰减（峰值形态影响不大，但"换手密集区"刻画弱于通达信原版）。
- 涨停一字板日（high==low）筹码全落单档，属正常。
- 停牌日（volume=0）不产生新筹码，分布冻结。
- 前复权后低价股档宽按全局价格范围均分，极端低价股（<2元）分辨率可能偏粗。
